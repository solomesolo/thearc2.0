# Day in the Life Snapshots

This directory contains static snapshot images for the "Day in the Life" section.

## Required Images

The following images should be placed here at 2x resolution:

1. `daylife-01-upload@2x.png` - Documents page with upload modal
2. `daylife-02-timeline@2x.png` - Timeline page with newly added event
3. `daylife-03-signals@2x.png` - Signals page with LDL trend expanded
4. `daylife-04-action@2x.png` - Command Center with action inbox
5. `daylife-05-marketplace@2x.png` - Marketplace filtered for lipid panel

## Image Specifications

- **Resolution**: 2x (e.g., 2400x1600px for a 1200x800px display)
- **Format**: PNG with transparency support
- **Aspect Ratio**: ~3:2 or 16:10 (will be cropped to fit)
- **File Size**: Optimized, ideally <500KB per image

## Fallback Behavior

If images are not found, the component will show an error state. For production, ensure all images are present and optimized.
